Holder statement

What I work on

I like building the backend of AI systems more than the AI itself. Most of what I build sits where Go meets Python: a Go service handling ingestion, concurrency and the API, next to a Python service doing embeddings, retrieval and model calls.

Right now I'm thinking about repository intelligence, RAG infrastructure, and what it takes to run these pipelines reliably at some scale instead of getting them to work once in a notebook.

I also read papers and rebuild the ideas myself. Writing RoPE or a KV cache by hand is usually the fastest way for me to understand how something works.

Distinguishing marks patterns that repeat across my repositories

Go for the service, Python for the model
KnowYourRepo, SmartFile Manager, Semantic-Duel and Social Music Graph all split the same way. A Go process owns concurrency, I/O and the API; a Python service owns embeddings and inference.
Let code check what a model can't be trusted with
ArchiGen hands layout to Graphviz and validation to a deterministic checker. JobBot diffs every résumé edit in code. The financial analyzer computes ratios with plain functions instead of asking the LLM.
Degrade instead of crashing
Validated multi-provider failover in JobBot and KnowYourRepo, a polling fallback when fsnotify misses events, a repair loop when a diagram fails validation.
Measure it, then publish the result
Prometheus and Grafana on KnowYourRepo, a metrics endpoint on Semantic-Duel, and a JobBot test audit that documents a 0/12 first run next to the 12/12 fix.

0/12 → 12/12adversarial real-LLM test matrix, before and after four fixes

  • Every rewritten section passes a skill whitelist, a guard against invented numbers, a word-retention check and a LaTeX injection gate. A failing section reverts on its own and the rest keeps its edits.

  • Six free-tier LLM providers with priority failover. The router retries on the next provider when a response fails validation, not only when a request errors.

Semantic-Duel

A real-time word game for two. A target word appears, both players have 60 seconds to submit related words, and the server scores each one by semantic similarity.

  1. ConnectWebSocket hub
  2. MatchFIFO queue
  3. Duel60 s room state machine
  4. Scorecosine vs. target
  5. Resultthen auto-requeue
~3,000words pre-embedded at 384 dimensions
1 ssubmission cooldown per player
  • Server-authoritative: game state and scoring never leave the server, which is the anti-cheat.
  • Embeddings are computed once in Python, so the Go server runs with no Python at runtime.
  • Ping/pong heartbeats, Unicode-normalised input and message passing over channels instead of shared locks.

Fly Brain

A spiking neural network wired from a real fruit-fly connectome and trained to play Flappy Bird.

  1. FetchneuPrint, male CNS v1.0
  2. Subgraphvisual → one hop → descending
  3. Encodegame state → input current
  4. SimulateLIF neurons, surrogate spikes
  5. Decodespike counts → flap
  6. LearnREINFORCE

τ · dV/dt = −(V − Vrest) + I(t)

  • Leaky integrate-and-fire neurons. Synapse signs follow each presynaptic neuron's neurotransmitter.
  • The connectome weights are registered as buffers, so the optimiser cannot touch them. Only the encoder into the visual neurons and the decoder out of the descending neurons learn.
