6Detailed Description

6.1Overview

I like building the backend of AI systems more than the AI itself. Right now that means repository intelligence, RAG infrastructure, and what it takes to run these pipelines reliably at some scale instead of once in a notebook. Four design rules repeat across the repositories:

Go for the service, Python for the model
A Go process owns concurrency, I/O and the API; a Python service owns embeddings and inference.
Let code check what a model can't be trusted with
Graphviz lays out diagrams, difflib reports résumé edits, plain functions compute financial ratios.
Degrade instead of crashing
Validated multi-provider failover, polling fallbacks, repair loops.
Measure it, then publish the result
Prometheus dashboards, metrics endpoints, and a test audit that shows the 0/12 run next to the 12/12 fix.
