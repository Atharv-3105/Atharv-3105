    About me

    Most people pick a side: research notebooks or production services. I like the seam between them, where a model has to become an API that answers in milliseconds and doesn’t make things up.

    On the model side I learn by rebuilding. From_Scratch is ten modules of ML, DL and RL written from first principles, from activation functions to attention variants, U-Net, VQ-VAE, DDPM, PPO and a spiking network wired from a fruit-fly connectome. In Language_Model_Implementations I rebuilt LLaMA 2, Gemma 3 and Qwen 3 block by block and trained a small language model with its own tokenizer.

    On the systems side I write the services around those models: a Go API with a bounded worker pool and per-client rate limits, a FastAPI sidecar that routes across five model providers, hybrid retrieval on pgvector, Server-Sent Events for streaming, and Prometheus metrics into Grafana.

    Right now I’m a software developer intern at Helionyex Solutions, building core modules of a climate data system in Electron, React, TypeScript and PostgreSQL.
